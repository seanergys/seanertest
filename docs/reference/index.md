# Reference

The reference describes every file format, option and test handle of seanertest. It states what
each setting means, not how to use it for a task; the [how-to guides](../how-to/index.md) do that.

| Page | Content |
| --- | --- |
| [Fixture file](fixture-file.md) | `fixture.yaml`, the nodes and services of one test. |
| [Test API](test-api.md) | The pytest fixtures and the service handles that tests receive. |
| [Command line](command-line.md) | The pytest options, `python -m seanertest.build`, the scripts and the environment variables. |
| [Configuration file](configuration-file.md) | `config.yml`, the settings that apply to every target. |
| [Target file](target-file.md) | The files in `targets/`, which describe the machines. |
